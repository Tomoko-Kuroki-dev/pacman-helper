# pacman-helper

Una interfaz sencilla para gestionar paquetes de Arch Linux usando pacman.

## Funciones

- Instalar paquetes
- Actualizar bases de datos
- Actualizar el sistema
- Buscar paquetes
- Consultar información de paquetes
- Eliminar paquetes

## Instalación

```bash
./install.sh
```

## Uso

```bash
pacman-helper
```

## ¿Porqué?

Para la gente floja (como yo jsjs) que quiere automatizar todo
